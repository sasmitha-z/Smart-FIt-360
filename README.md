#SmartFit360 
*Measure once. Use everywhere.*

SmartFit360 is a proposed smart tailoring and fit platform designed to help users reuse their body measurements for online shopping and customised clothing.

## Main Features

- *SmartMeasure:* Explore camera and distance-sensor-assisted body measurement.
- *SmartFit:* Compare user measurements with clothing and footwear size information.
- *SmartPattern:* Generate customised sewing patterns for selected clothing designs.

## Initial Project Scope

The first version will focus on a limited set of measurements, selected clothing size charts, and two or three supported pattern designs. Measurement accuracy will be tested against manual measurements.
